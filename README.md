# 📱 Digital Mobile App

**Digital Mobile App** is a modern Flutter-based remittance application.  
It provides a secure, user-friendly way to send money, manage beneficiaries, and perform identity verification — all in a mobile-first experience.

---

## 🚀 Features

- ✅ **User onboarding & authentication**
- ✅ **Secure KYC / identity verification**
- ✅ **Beneficiary management**
- ✅ **Send money quickly & securely**
- ✅ **Face detection, text recognition & object detection**
- ✅ **PDF generation & sharing**
- ✅ **Push notifications**
- ✅ **In-app updates**
- ✅ **Rich UI with custom animations & SVG support**
